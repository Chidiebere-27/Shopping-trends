****Customer Purchase Behaviour Analysis (Python | Jupyter)****
**Overview**

This project analyses a Kaggle retail dataset containing 3,000+ records and 19 customer and transaction-related features.

Key columns include:

**Demographics:** Age, Gender, Location

**Purchasing behaviour:** Item Purchased, Category, Purchase Amount (USD), Season

**Customer engagement:** Review Rating, Subscription Status, Frequency of Purchases

**Transaction details:** Payment Method, Preferred Payment Method, Shipping Type

**Promotions:** Discount Applied, Promo Code Used

**Historical data:** Previous Purchases

****What I Did****

Data cleaning and preprocessing

Exploratory data analysis (EDA)

Behavioural trend analysis

Customer segmentation insights

Visualisation of spending and frequency patterns

****Tools Used****

Python • Jupyter Notebook • pandas • NumPy • Matplotlib / Seaborn

****Skills Demonstrated****

Data wrangling • Consumer analytics • Insight generation • Visual storytelling • Business-focused interpretation
